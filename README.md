# Web CRUD Stok Barang

Aplikasi manajemen stok barang berbasis web yang dibuat untuk memenuhi tugas Praktik Kerja Lapangan (PKL).

## Fitur Utama
* **Create**: Menambah data barang baru
* **Read**: Menampilkan daftar stok barang
* **Update**: Mengubah informasi data barang
* **Delete**: Menghapus data barang

## Teknologi yang Digunakan
* **PHP** (Native)
* **MySQL** (Database)
* **HTML5 / CSS3 / JavaScript**
* **Bootstrap 5** *(opsional, hapus jika tidak pakai)*

## Cara Menjalankan di Lokal (XAMPP)
1. *Clone* atau *download* repository ini.
2. Pindahkan folder projek ke dalam directory `C:/xampp/htdocs/`.
3. Buka **phpMyAdmin** (`http://localhost/phpmyadmin`).
4. Buat database baru bernama `db_stok_barang`.
5. *Import* file `.sql` yang ada di dalam folder projek.
6. Akses aplikasi di browser melalui `http://localhost/web-CRUD-stok-barang`.
